# Nexus Desktop

一個放在 macOS 螢幕頂端正中央的小工具，外觀與操作方式參考 iPhone 的動態島。平常是一顆小小的黑色島，滑鼠移過去就展開，可以控制音樂、暫存檔案、看行程、找回剪貼簿紀錄、監看電腦狀態。

- 有瀏海的 MacBook：島會貼著瀏海，看起來像瀏海變大了。
- 沒有瀏海的螢幕（Mac mini、外接螢幕）：顯示一個小膠囊，也可以設成完全貼平，平常看不到，滑鼠移到螢幕頂端中間才出現。

> 本工具為個人開發的非官方軟體，與 Apple 無關。

---

## 功能

**動態島**
- 播音樂時，兩側顯示專輯封面和跳動的音量條，顏色會跟著封面變。
- 滑鼠停一下，展開預覽卡片：音樂、行程、檔案抽屜、剪貼簿、系統狀態、待辦。
- 點一下（或按 `⌥ Space`）打開完整面板。
- 調音量、調亮度、換歌、充電、藍牙耳機連線、行程快開始時，島會自動冒出來提醒。
- 把檔案拖到島上就能暫存，之後再拖出去、打開或 AirDrop。

**完整面板**

| 分頁 | 可以做什麼 |
| --- | --- |
| 控制 | Wi-Fi、深色模式、藍牙、夜覽、音量、正在播放 |
| 監控 | CPU、記憶體、硬碟、網路，佔用最多資源的程式 |
| 應用程式 | 搜尋並打開 App、檔案，自訂常用文字片段 |
| 剪貼簿 | 複製紀錄、搜尋、釘選（會自動略過密碼管理器） |
| 桌布 | 從資料夾換桌布、隨機、最愛、定時輪換 |
| 今日 | 時鐘、下一個行程、待辦、筆記、常用捷徑 |
| 電源 | 鎖定、睡眠、登出、重新開機、關機 |
| 設定 | 島的大小、外觀、快捷鍵、延伸螢幕、剪貼簿規則、檢查更新 |

---

## 系統需求

- macOS 13 以上
- Apple 晶片的 Mac（M1、M2、M3、M4…）。Intel Mac 不支援。

---

## 安裝

1. 到 [Releases](https://github.com/paulshen0117/nexus-desktop-releases/releases/latest) 下載最新的 `.dmg`。
2. 打開 `.dmg`，把 **Nexus Desktop** 拖進「應用程式」資料夾。
3. 這個 App 沒有 Apple 付費簽名，第一次打開時 macOS 會擋下來。打開「終端機」，貼上這行後按 Enter：
   ```
   xattr -dr com.apple.quarantine "/Applications/Nexus Desktop.app"
   ```
4. 打開 Nexus Desktop，螢幕頂端中間就會出現島。

**之後會自動更新**：App 打開 15 秒後、以及之後每 6 小時，會自動檢查新版並在背景下載，下次打開時套用。也可以到「設定 → 更新」手動檢查。

## 使用方式

| 想做什麼 | 怎麼做 |
| --- | --- |
| 看預覽卡片 | 滑鼠移到島上停一下 |
| 打開完整面板 | 點一下島，或按 `⌥ Space` |
| 收起面板 | 按 `Esc`、點面板外面，或在觸控板上往上滑 |
| 切換面板分頁 | `⌘1` ～ `⌘8`，或點左邊選單 |
| 搜尋 App／檔案 | `⌘⇧ Space` |
| 切歌 | 在預覽卡片上用觸控板左右滑 |
| 暫存檔案 | 把檔案拖到島上 |
| 看所有快捷鍵 | 在面板裡按 `?` |

快捷鍵可以到「設定 → 一般」更改。

**Mac mini／外接螢幕的建議設定**
- 想要平常完全看不到：「設定 → 動態島」把高度拉到 0（貼平）。
- 接了好幾個螢幕、想讓島跟著滑鼠跑：打開「在延伸螢幕顯示動態島」。

## 權限

第一次用到時，macOS 會詢問以下權限，按「允許」即可：

| 權限 | 用途 |
| --- | --- |
| 行事曆 | 在島和「今日」顯示接下來的行程 |
| 控制其他 App（自動化） | 控制 Spotify／Apple Music 播放、電源動作、取得專輯封面 |

因為沒有 Apple 付費簽名，更新後 macOS 有時會再問一次，再按一次允許就好。

---

## 隱私

- 所有資料（設定、剪貼簿紀錄、待辦、筆記）都只存在你自己的電腦裡，不會上傳到任何地方。
- 唯一的連網動作：檢查更新，以及下載 Spotify 的專輯封面圖片。
- 剪貼簿會自動略過常見的密碼管理器（鑰匙圈、密碼、1Password、Bitwarden），也可以在設定裡加入其他要略過的 App，或暫停紀錄。

## 常見問題

**打開時說「無法打開，因為無法驗證開發者」**
照「安裝」第 3 步，在終端機執行那行指令。

**行事曆按了允許沒反應**
到「系統設定 → 隱私權與安全性 → 行事曆」，手動打開 Nexus Desktop。

**看不到島**
可能是設成貼平（高度 0），把滑鼠移到螢幕頂端正中間就會出現。也可能是正在全螢幕播放影片，島會自動藏起來。

**沒有專輯封面**
第一次會問「Nexus 想要控制 Spotify」，要按「好」。

**想移除**
把「應用程式」裡的 Nexus Desktop 丟到垃圾桶。要連資料一起刪，再刪掉這兩個資料夾：
```
~/Library/Application Support/app.nexusisland.desktop
~/Library/Caches/app.nexusisland.desktop
```
